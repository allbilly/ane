# Full-model macOS CPU and ANE repeats

On 2026-10-07, three CPU and three ANE runs completed the six-prompt,
64-decode-call protocol from `todo.md`. All 1,170 prediction choices per path
matched the floating reference. Maximum full-logit normalized RMSE was
**0.05817% for CPU** and **0.48789% for ANE**, below the unchanged 0.5% gate.

This is full-model execution: every body projection runs on ANE, while CPU
runs recurrence, attention and the vocabulary head. macOS compiles and
executes MIL through ANEForge's private E5RT runtime, with ANE-only device
mask 4. Each input makes 96 E5RT projection executions; internal hardware
task-dispatch counts are not measured. Each run made 339,552 timed projection
executions for 3,153 prompt tokens plus 384 decode calls.

The accurate compensation policy matches Asahi: two K partitions, high and
residual FP16 planes, power-of-two input scaling and gains 1.0/1.375. The
checkpoint remains the pinned Mirai M revision
`c12202e4c764e559960827761566aaa1fd15a87a`. Both paths use four CPU workers,
context capacity 2,112, one BLAS thread and passive OpenMP waiting. The CPU
uses packed W4 SDOT; ANE uses resident FP16 body matrices.

## Observed timings

Rates combine the three repeats by total tokens divided by total elapsed
time. Warm TTFT includes the first greedy selection; setup, weight packing,
compilation, warmup, reset and comparisons are outside timed regions.

| Prompt group | CPU prefill tok/s | ANE prefill tok/s | CPU decode tok/s | ANE decode tok/s |
| --- | ---: | ---: | ---: | ---: |
| Four chats, 23/19/21/18 tokens | 30.54 | 13.22 | 26.42 | 12.46 |
| 1,024 tokens | 28.06 | 12.67 | 22.41 | 11.95 |
| 2,048 tokens | 25.48 | 12.11 | 21.02 | 10.93 |
| Aggregate | 26.38 | 12.31 | 24.63 | 12.09 |

All six timing runs were affected by paging or external desktop activity.
Host observations bracket every child process and continue every five
seconds; all shared ANE/GPU locks were held. Pageouts were
36,976/80,853/260,314/16,546/14/246 in execution order, with 336 swapouts in
ANE repeat one. The receipts retain external CPU samples and thermal queries.
These numbers establish completed execution and numerical validation; they
do not establish an isolated operating-system speed comparison.

The Mac trace metadata hash is
`f281795a189cd3214cc7457b5dcb471b9965d0990112ad89bb9ee0922be37ce4`.
The saved Asahi receipt uses a different trace hash. Prompt lengths, decode
counts, checkpoint and compensation policy match, but byte-identical
cross-host reference traces have not been established. Timed decode consumes
saved reference-generated tokens for numerical coverage, including calls
beyond EOS.

## Evidence and reproduction

[The evidence index](provenance/macos-full-model-20261007/files.json) hashes
the six raw result receipts, session observations, summary and the exact
measured source snapshots. JSON receipts are gzip-compressed to keep Git
small; decode them with `gzip -dc FILE.json.gz`. Every result retains
per-prompt timings, each prediction's error/match, model/trace hashes and
all 96 program MIL/weight identities. The measured compiler was Homebrew
GCC 16.2.0, and the E5RT dylib SHA-256 was
`017fbc08675e8773e73f5c0c44f6e6b040c14257342fdf4c0f19914044008587`.

With the pinned checkpoint, existing `~/Desktop/ANEForge` checkout and
prepared NumPy/OpenMP environment, choose new output directories:

```sh
env CC=gcc-16 OPENBLAS_NUM_THREADS=1 OMP_WAIT_POLICY=PASSIVE \
  qwen35/.venv/bin/python -m qwen35.tools.benchmark \
  --model MODEL_DIR --prepare-traces \
  --steps 64 --lengths 1024 2048 --threads 4 \
  --traces qwen35/local-results/new-macos-traces

env CC=gcc-16 OPENBLAS_NUM_THREADS=1 OMP_WAIT_POLICY=PASSIVE \
  qwen35/.venv/bin/python -m qwen35.tools.benchmark_macos \
  --model MODEL_DIR --traces qwen35/local-results/new-macos-traces \
  --output qwen35/local-results/new-macos-full-model
```

The runner verifies checkpoint hashes and the exact six-prompt protocol,
acquires `~/ane.lock` then `~/gpu.lock`, and alternates CPU/ANE execution order.
It requires at least three repeats and all numerical gates. Kernels and
model caches generated by private compilation stay outside Git. The macOS
adapter implements the accurate policy; legacy/scaled modes are unsupported.

The [BF16 oracle package manifest](provenance/macos-bf16-oracle-package-20261007.json)
also records a verified local archive of both macOS all-prefix captures and
their original report. Its large arrays stay ignored. Cross-host transfer and
comparison need the new Asahi arrays; compare existing files without rerunning
the model using:

```sh
qwen35/.venv/bin/python -m qwen35.tools.compare_prefix_captures \
  uzu-macos-all.npz uzu-asahi-all.npz --output cross-host.json
```
